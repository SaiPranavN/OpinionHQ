# OpinionHQ Agent Instructions

OpinionHQ is an entity-centric public-opinion intelligence platform.

Before planning or implementing any feature:

1. Read `docs/product-brief.md`.
2. Treat that document as the primary product source of truth.
3. Keep development limited to the MVP scope unless explicitly instructed otherwise.
4. Use TypeScript throughout the application.
5. Build a responsive web application.
6. Keep verified entity information separate from user-generated opinions.
7. Do not fabricate users, votes, comments, engagement, or production data.
8. You are allowed to use dummy but real time data for the protoype purpose. 
8. Add database migrations for schema changes.
9. Add tests for important business logic.
10. Update relevant documentation when architecture or product behavior changes.
11. Do not begin large implementation work without first proposing a plan.
